# GOSH plot dataset

GOSH plot dataset

## Usage

``` r
data("m.gosh")
```

## Format

Dataset of class `gosh.rma`.

## Source

Data generated by fitting a random-effects meta-analysis with `rma.uni`
using `dmetar`s in-built `ThirdWave` dataset, which was then provided as
input to the `gosh` function in `metafor`.
